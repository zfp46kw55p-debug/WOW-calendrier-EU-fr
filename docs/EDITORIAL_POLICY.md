# Politique éditoriale

## Objectif

Le projet **WoW Calendrier EU FR** a pour objectif de proposer le calendrier iCalendar (ICS) francophone le plus complet, fiable et maintenable pour **World of Warcraft Retail Europe**.

Ce dépôt ne cherche pas à remplacer les sites d'actualité ou les guides de jeu. Il a pour vocation de fournir une base de données événementielle cohérente, facilement exploitable par les applications de calendrier.

---

# Principes

## 1. Privilégier les sources officielles

Lorsque plusieurs traductions existent, le projet privilégie toujours :

1. le client officiel français de World of Warcraft ;
2. les publications officielles Blizzard France ;
3. Wowhead France ;
4. les autres sources communautaires reconnues.

---

## 2. Respecter les noms officiels

Les événements utilisent systématiquement leur appellation officielle française.

Exemples :

- Chemises à gogo
- Embarquement pour les Mille pointes
- Paléon'Goro
- Fête des chapeluisants

Aucune traduction personnelle n'est conservée lorsqu'une traduction officielle existe.

---

## 3. Les descriptions ne sont pas des guides

Les descriptions doivent présenter l'esprit de l'événement.

Elles ne doivent pas expliquer :

- comment terminer une quête ;
- où trouver tous les PNJ ;
- comment optimiser les récompenses.

Une description doit donner envie de participer sans remplacer un guide.

---

## 4. Descriptions courtes

Les descriptions doivent idéalement comporter une ou deux phrases.

Elles commencent de préférence par un verbe d'action.

Exemples :

- Rejoignez...
- Affrontez...
- Embarquez...
- Découvrez...
- Célébrez...
- Assistez...

---

## 5. Lieux

Le champ `location` indique uniquement le lieu principal de l'événement.

Il ne s'agit pas d'une liste exhaustive.

Exemples :

✔ Ancien Silithus

✔ Reflet-de-Lune

✔ Azsuna

✔ Sporeggar, Marécage de Zangar

---

## 6. Dates

Les dates correspondent au calendrier européen Retail.

Les dates de fin utilisent le principe iCalendar :

DTEND est exclusif.

---

## 7. Sources

Chaque événement doit citer au minimum une source.

Lorsque cela est possible :

- Blizzard France
- Wowhead France

sont privilégiés.

---

## 8. Neutralité

Le calendrier décrit les événements.

Il ne contient :

- aucun avis personnel ;
- aucune recommandation de jeu ;
- aucune stratégie.

---

## 9. Cohérence

Tous les événements utilisent :

- les mêmes conventions de rédaction ;
- le même ordre des propriétés JSON ;
- le même style de description ;
- la même politique de sources.

---

## 10. Pérennité

Les descriptions doivent rester valables dans le temps.

Éviter les formulations telles que :

- Nouveau !
- Cette année...
- Actuellement...
- Dernière mise à jour...

Le calendrier doit rester pertinent même plusieurs années après sa publication.

---

# Philosophie

Le fichier ICS est le produit final.

La véritable valeur du projet réside dans la qualité, la cohérence et la pérennité des données qui le composent.
