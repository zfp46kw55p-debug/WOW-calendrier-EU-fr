# 🎮 World of Warcraft – Calendrier EU FR

Calendrier communautaire francophone pour **World of Warcraft Retail – Europe**.

## Objectif

Proposer un calendrier importable (.ics) contenant :

- Événements mondiaux
- Trading Post
- Réinitialisation hebdomadaire
- World Boss
- Bonus hebdomadaires
- Marcheurs du temps
- Patchs officiels
- Début et fin des saisons
- Twitch Drops officiels
- Événements temporaires Blizzard
